# Skill catalog

Native installation is described in [agent compatibility](agent-compatibility.md). Skills can also be read directly by any file-capable agent.

| Skill | When to use |
| --- | --- |
| [project-discovery](../skills/project-discovery/SKILL.md) | Discover product goals, users, workflows, constraints, and MVP scope before starting a new software project. |
| [requirements-engineering](../skills/requirements-engineering/SKILL.md) | Turn an agreed product scope into measurable requirements and acceptance criteria; use for ambiguous behavior or changing requirements. |
| [system-architecture](../skills/system-architecture/SKILL.md) | Choose and document a proportionate system architecture, stack, boundaries, and trade-offs before significant implementation. |
| [frontend-design](../skills/frontend-design/SKILL.md) | Design or refine product interfaces around user tasks, brand, visual hierarchy, responsive states, and purposeful information density. |
| [frontend-engineering](../skills/frontend-engineering/SKILL.md) | Implement approved frontend behavior with reusable components, state handling, API integration, and responsive accessible HTML. |
| [backend-api-engineering](../skills/backend-api-engineering/SKILL.md) | Implement or review server endpoints, validation, authentication, resource authorization, transactions, and API error contracts. |
| [database-engineering](../skills/database-engineering/SKILL.md) | Design or change relational data models, integrity constraints, migrations, transaction behavior, and query plans. |
| [fullstack-development](../skills/fullstack-development/SKILL.md) | Build an approved feature across UI, API, database, tests, and documentation in small reviewable increments. |
| [security-engineering](../skills/security-engineering/SKILL.md) | Threat-model or assess authentication, authorization, data handling, dependencies, and API abuse when security review or risk warrants it. |
| [code-audit](../skills/code-audit/SKILL.md) | Review code correctness, architecture, maintainability, security, dependencies, and test gaps; produce evidence-backed prioritized findings. |
| [qa-testing](../skills/qa-testing/SKILL.md) | Plan and execute risk-based tests for user workflows, permissions, APIs, boundaries, regressions, and failure recovery. |
| [debugging](../skills/debugging/SKILL.md) | Reproduce, isolate, fix, and verify a concrete software failure without speculative unrelated changes. |
| [accessibility-review](../skills/accessibility-review/SKILL.md) | Review and remediate semantic HTML, keyboard behavior, focus, contrast, forms, and assistive technology support. |
| [performance-optimization](../skills/performance-optimization/SKILL.md) | Measure and improve an observed frontend, API, database, or resource bottleneck while preserving behavior. |
| [devops-deployment](../skills/devops-deployment/SKILL.md) | Prepare stack-appropriate deployment, CI, configuration, migrations, backups, rollback, and observability; use for release operations. |
| [documentation](../skills/documentation/SKILL.md) | Write or update practical software documentation grounded in actual behavior, setup, architecture, and operating evidence. |
| [release-readiness](../skills/release-readiness/SKILL.md) | Assess a candidate release using acceptance, security, QA, accessibility, operational, and rollback evidence before deployment. |
