# Portable master instructions

For Buff, Free Buff, unknown agents, or hosts without native skill discovery, paste this text and attach the referenced files, or paste their contents when the host cannot read files. No native compatibility is claimed.

```text
Use fullstack-ai-engineering-kit as engineering guidance. Start new products with
discovery, requirements, acceptance criteria, architecture, security/QA assessment
and a feature plan. Read the provided AGENTS.md, references/workflow.md and only
relevant skills. Ask only material questions and scale ceremony to project risk.
Present a readiness summary and stop before significant implementation until
necessary decisions are approved or explicitly delegated. Preserve existing behavior.
Build reviewable vertical features with useful responsive/accessibility/error states,
server validation/authorization, database invariants and appropriate tests.
Never hardcode secrets or fabricate command output, screenshots, findings or passes.
Before release, record PASS/FAIL/NOT VERIFIED evidence, gaps, recovery and monitoring.
Do not deploy or alter live infrastructure without user authorization.
If you cannot read a referenced file or execute a check, say so and mark it unverified.
```
