# Workspace redesign

Mode: Operate. Scope: app shell, dashboard, login, session browsing, and shared UI tokens. Teachers need to find a class, resume checking, and review results quickly.

## Direction contract

THESIS: A precise teacher workspace with navigation separated from paper-checking work.

OWN-WORLD: Forest-green shell, cool mist work area, white working surfaces, restrained emerald selection, Geist text, 12px surface corners and 8px controls.

STORY: Teachers see where they are, resume a real session, or prepare a class. Empty and failed requests show explicit next steps; no invented activity or metrics.

FIRST VIEWPORT: Desktop fixed 232px navigation rail, contextual top bar, left-aligned page title, compact real-data summary, wide recent-session list beside a narrower setup guide. Phone uses top branding and bottom navigation; content becomes a single column. Signature: a connected capture–review–save sequence showing the actual checking workflow.

FORM: Standard web workspace; code-led; seed: none (unavailable).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Finish review

Implemented the chosen workspace, checking sequence, live-data dashboard, session search, empty states, sign-in styling, and launch branding. Existing grading, imports, authentication, and database structure remain in place. TypeScript, lint, 33 regression tests, production/PWA build, and five server-render checks pass. Source review found and corrected session-list cache refresh after creation, deletion, and key confirmation. No new dependencies.

Verdict: implementation and automated checks complete; rendered desktop/mobile visual review is pending. The browser inventory returned no connected browsers, so screenshots and live interaction checks could not be performed. DESIGN.md records the implemented system. PWA raster icons are generated by the existing source-controlled icon script.
